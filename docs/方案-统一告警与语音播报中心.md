# 方案书｜统一告警与语音播报中心（音效 + 中文语音）

> 目标：把"声音"从现在的**单一蜂鸣**升级为**分级音效 + 中文语音播报**的统一播报中心，
> 覆盖：视觉颜色检测、安全围栏越界、系统预警、报警（急停/下发拦截/鉴权失败/链路掉线）。
> 版本：v1 · 2026-09-23 · 依赖：浏览器原生 WebAudio + Web Speech API（**零素材、零依赖、可离线**）

---

## 0. 结论

| 问题 | 结论 |
|---|---|
| 能做吗 | **能。** 浏览器原生 `AudioContext`（合成音效/旋律）+ `speechSynthesis`（中文语音）就能做全，不需要任何音频文件、不需要联网、不需要后端。 |
| 现在的短板 | `utils/alarm.js` 只有"方波蜂鸣"：danger 1Hz / hit 3Hz，**没有语音、没有分级旋律、没有队列、没有去重**，长时间报警会很吵且不知道发生了什么。 |
| 升级后 | 四级告警 × 各自旋律 + 中文语音播报 + 优先级队列 + 节流去重 + 静音/免打扰 + 播报历史 + 一键试听。 |
| 现场音柱 | 浏览器方案适合"有人值守的操作台"；车间要**音柱/声光报警**时，加可选后端通道（Windows SAPI / pyttsx3 / 串口声光报警器），接口预留。 |

## 1. 告警分级矩阵（核心设计）

| 级别 | 典型事件 | 视觉 | 音效 | 语音 | 重复/节流 |
|---|---|---|---|---|---|
| **safe / clear** | 围栏恢复安全 | 绿 | 单音上行「叮—咚」 | "围栏已恢复安全"（可关） | 仅状态变化时一次 |
| **info** | 登录成功、下发成功、试运行通过、相机打开 | 蓝 | 短促「滴」 | 默认**不播**（仅记录） | 15s 去重 |
| **warn 预警** | 围栏 `warn`、围栏互锁缺失、链路抖动、相机掉线、点动看门狗超时 | 黄 | 双音「滴—滴」(660Hz×2) | "预警：围栏接近警戒区" | 30s 去重 |
| **error 报警** | 围栏 `danger`、下发被拦截、执行失败、鉴权失败、IK 超限位 | 橙红 | 三连音「嘟嘟嘟」(520Hz×3) | "报警：安全围栏进入危险区，已禁止下发" | 10s 去重 |
| **critical 紧急** | 围栏 `hit`（碰撞）、急停触发、Modbus 掉线、服务异常 | 红 | **警笛旋律**（880↔1180Hz 交替 6 拍）+ 循环 | "紧急：机器人已进入禁区，请立即急停"（循环 2 次） | 5s 去重，可打断低优先 |

**优先级**：`critical(4) > error(3) > warn(2) > info(1)`。高优先级**抢占**正在播放的低优先级语音（`speechSynthesis.cancel()` 后播报），同级按时间排队。

## 2. 音效设计（WebAudio 合成，不用任何音频文件）

统一用 `OscillatorNode + GainNode` 包络合成，四种波形与包络：

| 音效 | 波形 | 频率序列（Hz） | 单音时长 | 间隔 | 听感 |
|---|---|---|---|---|---|
| `ok`（恢复/成功） | sine | 660 → 880（上行） | 0.12s | 0.10s | 「叮—咚」确认感 |
| `info` | sine | 880 | 0.08s | — | 轻「滴」 |
| `warn` | triangle | 660, 660 | 0.10s | 0.14s | 双音提示 |
| `error` | square | 520 ×3 | 0.11s | 0.13s | 三连「嘟嘟嘟」 |
| `critical` | sawtooth | 880/1180 交替 6 拍 | 0.16s | 0.16s | 警笛（循环，直到状态解除） |
| `vision` | sine | 990 → 1320 | 0.09s | 0.07s | 清脆「叮铃」（检测成功） |

* 音量默认 `0.12`（`error/critical` 稍高），全局音量滑块 0~100%。
* **浏览器自动播放策略**：首次用户手势（点击/按键）时 `ctx.resume()`；未解锁前只排队不发声，UI 提示"点击页面以启用声音"。

## 3. 语音设计（Web Speech API，`lang=zh-CN`）

### 3.1 文本模板（可配置，默认如下）

| 触发 | 模板 |
|---|---|
| 围栏 warn | `预警：机器人接近{fence.zoneName}，余量 {fence.clearance} 毫米` |
| 围栏 danger | `报警：已进入危险区{fence.zoneName}，运动已禁止` |
| 围栏 hit | `紧急：机器人越界碰撞风险，请立即急停` |
| 围栏恢复 | `安全围栏已恢复正常` |
| 急停触发 | `紧急停止已触发，执行引擎已锁定` |
| 下发被拦截 | `下发被拦截：安全围栏互锁生效` |
| 控制权限失效 | `控制令牌已过期，请重新获取控制权限` |
| 鉴权失败 | `权限不足：该操作需要管理员权限` |
| 链路掉线 | `机器人链路断开，正在尝试重连` |
| 相机掉线 | `相机连接中断，请检查相机电源与网口` |
| 执行完成 | `已下发目标到位，模式{mode}` |
| 试运行通过 | `试运行测试通过，共 {count} 步` |
| 试运行失败 | `试运行发现问题：{name}，第 {index} 步{reason}` |
| **视觉检测** | `检测到{color}物体，置信度{conf}` |
| 视觉未识别 | `颜色未能识别，请人工复核` |

### 3.2 队列与去重

```
enqueue({ level, key, text, sound, repeat })
  · key 去重：同一 key 在 minInterval 内只播一次（warn 30s / error 10s / critical 5s）
  · 优先级抢占：更高 level 立即 cancel 当前语音并插队
  · 连续播报上限：单条最多 repeat 次（critical 2 次），防止刷屏
  · 静音/免打扰：静音时只保留视觉提示；critical 可配置"强制突破静音"
```

### 3.3 语音参数

* 音色：优先选 `zh-CN` 语音（Windows 通常有 `Microsoft Huihui/Yaoyao/Kangkang`），可在面板下拉选择。
* 语速 `rate` 默认 1.0（可调 0.8~1.4），音调 `pitch` 1.0，音量跟随全局音量。

## 6. 防骚扰策略（工业现场必须）

1. **分级节流**：warn 30s / error 10s / critical 5s（同一 key）。
2. **状态去重**：围栏状态未变化则不重复播报（恢复时才播"已恢复"）。
3. **免打扰时段**：可设"夜间只保留 critical"。
4. **一键静音**：顶栏图标一键静音（状态持久化），critical 可配置为强制突破。
5. **播报历史**：最近 20 条（时间/级别/文案），可清空 —— 声音错过了还能看。
6. **试听按钮**：每个级别一个"试听"，现场调音量不靠等事故。

## 8. 验收标准

| 项 | 标准 |
|---|---|
| 围栏 safe→warn→danger→hit | 音效与语音逐级升级，状态不变不重复播报 |
| 恢复 | 播一次"已恢复安全"并停止循环警笛 |
| 事件总线 warn+ | WS 事件到达即按模板播报，节流生效 |
| 视觉检测 | 每次成功判定播报颜色（含置信度），未识别播"请人工复核" |
| 静音 | 静音后无声（critical 可强制突破） |
| 刷新页面 | 配置保持；音频未解锁时提示"点击启用声音" |
| 性能 | 语音不阻塞渲染；连续 50 条事件不卡界面 |
| 兼容 | Chrome/Edge（Web Speech 中文可用）；Firefox 降级为仅音效 |

## 10. 与既有模块的兼容约定

1. **不破坏** `utils/alarm.js` 的导出（`setAlarmEnabled / getAlarmEnabled / updateAlarm`），SafetyPanel 的"声音"复选框照旧工作。
2. 播报中心**不参与**围栏判定与运动控制，纯表现层 —— 关掉它不影响任何安全链路（安全由后端互锁兜底）。
3. 图标全部 SVG，不引入 emoji（沿用项目规范）。
