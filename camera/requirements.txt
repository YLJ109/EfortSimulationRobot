# =====================================================================
#  视觉检测服务依赖 (camera/camera_service.py)

#  注意: 本服务与后端使用**不同的解释器**。原因:
#    - 海康 MVS SDK 的 Python 封装 (MvCameraControl_class.py) 不打在 PyPI 上,
#      随 MVS 客户端安装或从厂商样例包获得;
#    - ultralytics 会拉入 PyTorch, 体积可达数 GB, 不该塞进后端 venv。
#
#  因此视觉服务的解释器由 EFORT_CAMERA_PYTHON 指定 (见 .env.example),
#  默认复用参考项目 EFORT_Camera_Python_OpenCv 的 venv。
#  若要新建独立环境, 安装本文件后, 再把 MVS 的 MvImport 目录加到 sys.path
#  (由 EFORT_MVS_SDK_DIR 指定, 见 camera_service.py 顶部)。
# =====================================================================

#   升级时显式地改这里的上界 + 重跑 camera 相关回归, 不要靠 pip 自己飘。
